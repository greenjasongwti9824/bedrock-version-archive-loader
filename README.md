## Overview

Bedrock Version Archive is a web-based directory of Minecraft Bedrock Edition releases distributed as Windows APPX packages. By collecting the available versions in one place, it lets users find a release and open its direct download link without checking multiple separate listings.

The directory is useful for Windows users looking for an earlier Bedrock Edition build or comparing packages from different points in the release history. Its package links lead to Microsoft CDN locations; Windows installation and automatic-update behavior are still controlled by the user's own system and Minecraft configuration.

## Troubleshooting Guide

### Nothing happens when I select a download

Verify the network connection and retry the link with a current Windows browser. Availability of Microsoft-hosted files can change separately from the archive itself.

### Windows refuses to install the APPX file

Make sure the package matches your Windows environment and that your account is allowed to install APPX packages. Check the applicable Windows package-installation requirements before trying again.

### A newer version returns after installation

Automatic updates can replace an installed Bedrock Edition package with a newer release. Review the project's automatic-update guidance and inspect the related Windows or Microsoft Store settings.

### A historical download link no longer works

The directory may continue to list an older release even if its Microsoft CDN file is no longer available. Try another package in the archive or check the link again later.

### The archive website will not open

Reload the page and confirm that the repository site is accessible. You can also test another browser or network connection; the hosting service may be experiencing a temporary outage.

## Frequently Asked Questions

### Will the archive update Minecraft for me?

No. The project supplies a browsable version directory and direct download links. Version selection, downloading, and installation all remain manual.

### Are earlier Bedrock Edition versions listed?

The archive is intended to contain multiple Minecraft Bedrock Edition APPX packages, including older releases when those packages are available.

### What servers host the downloads?

The package links lead to Microsoft CDN servers.

### Does the project store downloaded APPX files?

No local package copies are provided by the archive. Your browser and Windows determine where downloaded APPX files are saved.

### Can this be used to install an older version?

It can help you locate an older package for installation. The actual rollback process depends on your existing Windows installation, the selected package, and the update configuration on your device.

### Where is information about automatic updates?

The archive provides guidance for disabling automatic updates so a manually selected release is not immediately replaced by a newer one.

### Will every package work on every Windows system?

Not necessarily. Compatibility depends on the Windows environment, package version, and installation requirements. Confirm the release details and your system configuration before installing.
